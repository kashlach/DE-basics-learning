## DE-basics-learning

Репозиторий с учебными проектами по направлению Data Engineering (+ добавляю BI): от простейшего etl на pandas до полноценного пайплайна с Airflow, dbt, Grafana и Superset ([тык и сразу к нему](https://github.com/kashlach/DE-basics-learning/tree/main/currency-rate-project)).

### О себе

**Текущий опыт**: 3 года PL+ и PL/SQL разработчиком + 9 месяцев в роли аналитика (работа с операционной отчетностью).

**Ключевые навыки из коммерческого опыта**:

- Написание сложных оптимизированных запросов для больших объемов данных (Oracle *преимущественно*, PostgreSQL, чуть-чуть MS SQL Server)
- Разработка функций, хранимых процедур и джобов на PL/SQL
- Построение постраничных/сводных отчетов в Oracle Reports Builder и MS Report Builder

**Мотивация**: движение в сторону от "формирователя" отчетов к более независимой позиции аналитика-инженера, способного самостоятельно проектировать систему отчетности.

## Пройденный путь и освоенные навыки
### Week 1 - Основы etl и работа с данными
**Проект**: pandas_simple_etl

Простейшийи etl-скрипт для анализа продаж из csv. Объединяет данные о продажах с информацией о районах доставки, очищает данные и сохраняет отчеты-csv'шки.

**Освоено**:

* ETL-пайплайн на Python
* Базовые операции pandas (`read_csv`, `groupby`, `merge`, `agg`)
* Создание виртуального окружения (`venv`) и файла `requirements.txt`
* Работа с Git и GitHub
* Markdown синтаксис для написания документации

### Week 2 - API → Python → PostgreSQL
**Проект**: github_events_etl

Скрипт для получения 100 последних публичных событий из GitHub Events API, сохранения полученных данных в PostgreSQL (распарсенные поля в одну таблицу, сырой JSON - в другую) и выполнения нескольких SQL запросов из Python.

**Освоено**:

* Запрос к **REST API** (библиотека `requests`, обработка JSON-ответа)
* Запуск **PostgreSQL** в **Docker**
* Работа с БД из Python (**SQLAlchemy**, `to_sql()`, `text()`)
* Работа с `JSONB` в PostgreSQL
* Выполнение запросов через `docker exec` (запуск SQL-файлов и разовых команд в контейнере для отладки и выгрузки CSV)
* Более продуманная работа с зависимостями ( `requirements.in с минимальными версиями → pip freeze > requirements.txt`)

### Week 3 - Оркестрация и DWH концепции
#### 3.1 Автоматизация загрузки GitHub Events
**Проект**: autoparse_github_events.py

По сути [прошлый проект](#week-2---api--python--postgresql), но автоматизированный: DAG запускает парсер каждые 5 минут и логирует запуски в БД.

**Освоено**:

* Контейнеризация с помощью **Docker Compose**
* Взаимодействие с PostgreSQL через `PostgresHook` (с метабазой Airflow и целевой БД)
* Разработка **DAG в Airflow**
* Использование `PythonOperator`, `BashOperator` и `BranchPythonOperator`
* Обмен данными между тасками через `XCom`
* Использование `Variables` (счетчик запусков)
* Мониторинг выполнения тасков через **Web UI Airflow** и **pgAdmin**

#### 3.2 SCD Type 2 реализация
**Проекты**: source_dag.py, staging_dag.py, scd2_dag.py

Инкрементальная загрузка данных из источника (таблица Customers) в staging-слой и сохранение полной истории изменений атрибутов клиентов (SCD Type 2).

**Освоено**:

- Работа с `XCom` для передачи данных между разными DAG'ами
- Логирование через библиотеку `logging`
- **DWH концепции**: SCD Type 2, Staging-слой, Dimension-слой
- **ELT-подход**
- `MERGE`-операции в PostgreSQL

****Архитектура**:

- **Source** - имитация микросервиса с данными о клиентах
- **Staging** - промежуточный слой для сырых данных (маркировка операций: I/U/D)
- **Dimension** - слой с SCD Type 2 историей (суррогатные ключи, флаг `is_active`)

### Итоговый проект - Комплексный ELT-пайплайн
**Проект**: currency-rate-project

Полноценный пайплайн для сбора, трансформации и визуализации данных о курсах валют ЦБ РФ.

Находится в стадии доработки.

**Схема проекта**:

```text
API ЦБ РФ → Airflow DAG → PostgreSQL (raw-слой, JSONB) → dbt (staging → intermediate → marts) → Grafana и Superset дашборды + Excel-отчеты + Email-алерты
```

**Освоено**:

- `uv` - менеджер пакетов (как замена `pip` и `venv`)
- `ruff` - форматирование Python-кода
- `pytest` - тестирование Python-кода
- **Dockerfile** - создание образа Airflow с dbt и superset с psycopg2-binary
- **dbt** - трансформация данных (модели, тесты, документация)
- **Grafana** - визуализация данных и настройка алертов
- **Superset** - визуализация данных
- Excel-отчетность - еженедельные отчеты, автоматическая отправка на почту

**Ключевые компоненты**:

- dbt-модели (три слоя):
  - Staging: очистка и подготовка сырых данных
  - Intermediate: агрегации и джойны
  - Marts: готовые витрины для дашбордов / отчетов
- Grafana дашборды:
  - Бизнес-дашборды: курсы валют (USD, THB и общий, не параметризованные, захардкоженные)
  - Технический дашборд: ETL Healthcheck с алертом при простое >24 часов
- Superset дашборды:
  - для анализа качества данных в БД;
  - для анализа динамики курсов валют к рублю за период;
- Отчетность:
  - Еженедельный Excel-отчет (автоматически по понедельникам, отправка на почту)
  - Сводный отчет через Power Query
  - Алерт по USD при изменении >2% за сутки
- Тесты:
  - API-клиент: проверка URL и формата даты
  - Загрузчик: проверка upsert-логики
